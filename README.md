# 研究室 共通機器・部屋予約システム (Kitanishi Lab Reservation System)

研究室メンバー間で共通の機器や部屋（顕微鏡、遠心機、PCRマシン、シーケンサー、セミナー室など）を効率的に予約・視覚化し、データはすべて **Google Drive（Google スプレッドシート）** 上で安全に共有・自動保存できるWebアプリケーションです。

---

## 🌟 主な機能

1. **タイムライン・カレンダー可視化**
   - リソースごとの予約状況が時間軸ブロックで一目で把握できます。
   - 24時間表示 / 営業時間表示（8:00〜22:00）の切り替えに対応。
   - 使用者名・利用時間・備考（使用目的など）を直感的に確認・ホバー表示。

2. **ダブルブッキング（重複予約）自動防止**
   - 同じ機器・部屋に時間が重なる予約を行おうとすると、自動的に警告が表示され登録を抑止します。

3. **Google Drive連携 (Google Apps Script)**
   - サーバー契約やデータベース構築は不要！
   - 無料のGoogleスプレッドシートがそのままデータベースとして機能します。
   - 研究室メンバー全員でGoogle Drive上でデータ共有可能。

4. **ローカルデモモード対応**
   - GAS連携設定前でも、ブラウザで `index.html` を開くだけで即座に試用動作確認ができます。

5. **機器・部屋の自由な追加・管理**
   - カテゴリー（顕微鏡、遠心機、分析機器、部屋など）や設置場所の管理。

## 🚀 使い方・環境構築手順

### 【ステップ 1】 ローカルで動作確認（デモモード）
1. `index.html` をダブルクリックするか、Google Chrome などのブラウザにドラッグ＆ドロップして開きます。
2. 画面上にタイムラインが表示され、新規予約や削除がテストできます。

---

### 【ステップ 2】 Google Drive（スプレッドシート）との連携設定

データ共有を行うために、Google Drive上に1つスプレッドシートを作成します。（所要時間：約3分）

#### 1. Google スプレッドシートの作成
1. [Google Drive](https://drive.google.com/) を開き、「新規」 > 「Google スプレッドシート」を作成します。
2. ファイル名を任意の名前に設定します（例: `KitanishiLab_機器予約データ`）。

#### 2. Google Apps Script (GAS) の貼り付け
1. スプレッドシートの上部メニューから **「拡張機能」 > 「Apps Script」** を開きます。
2. エディタに既にあるコード（`myFunction`）をすべて削除し、プロジェクトフォルダ内の `gas_backend.js` の内容をすべてコピー＆ペーストします。
3. エディタ上部の「保存」アイコン（フロッピーディスク）をクリックします。

`gas_backend.js` には、機器予約専用の共通カレンダーIDが設定されています。予約はこの共通カレンダーに作成され、予約画面で入力されたGoogleメールアドレス1名だけがゲストとして招待されます。

#### 3. データベースの初期自動構築（初回のみ）
1. エディタ上部の関数選択ドロップダウンで `setupDatabase` を選択します。
2. **「実行」** ボタンをクリックします。
3. 初回実行時、アクセス許可の承認を求められます：
   - 「権限を確認」 > 「アカウントを選択」 > 「詳細」 > 「（安全ではないページ）に移動」 > 「許可」をクリックします。
4. スプレッドシートに戻ると、`Reservations` と `Resources` の2つのシートが自動生成され、初期リソースデータが自動登録されます！

既存のスプレッドシートで更新する場合も `setupDatabase` をもう一度実行してください。既存予約を残したまま、`Reservations` シートに `GuestEmail` 列が追加されます。

#### 4. Webアプリとしてデプロイ（公開）
1. GASエディタ右上の **「デプロイ」 > 「新しいデプロイ」** をクリックします。
2. 歯車アイコン（種類を選択）から **「ウェブアプリ」** を選択します。
3. 設定を以下のように入力します：
   - **説明**: `Kitanishi Lab 予約API`
   - **実行するユーザー**: `自分`
   - **アクセスできるユーザー**: `全員`（または `Google アカウントを持つ全員`）
4. **「デプロイ」** をクリックし、発行された **「ウェブアプリ URL」** をコピーします。
   *(URLの末尾が `/exec` で終わるものです)*

既存のWebアプリを更新する場合は、**「デプロイ」 > 「デプロイを管理」 > 編集** から新しいバージョンを選び、再デプロイしてください。コードを保存しただけでは公開中の `/exec` に反映されません。

#### 5. Webアプリでの連携URL設定
1. `index.html` をブラウザで開きます。
2. 右上の **「Drive設定」** ボタンをクリックします。
3. 先ほどコピーした「ウェブアプリ URL」を貼り付け、**「設定を保存して接続」** をクリックします。
4. 右上のステータスが **「Google Drive 連携中」** に変わり、全メンバー間でのリアルタイム同期が可能になります！

## 📱 スマートフォン・タブレットからの利用手順

スマートフォンやタブレットのブラウザからURLにアクセスするだけで利用できるようにするための手順です。

### 【方法1】 GitHub Pages 等の無料Webホスティングで配信（推奨）
1. プロジェクトフォルダ（`index.html`, `styles.css`, `app.js`, `manifest.json`）を GitHub リポジトリ等にアップロードします。
2. リポジトリ設定の **Pages** で `main` ブランチを有効化し、公開URL（例: `https://<username>.github.io/<repo>/`）を発行します。
3. スマホ・タブレットのブラウザ（Safari / Chrome）で公開URLを開くだけで即座にご利用いただけます！
4. **スマホのホーム画面に追加（PWA）**:
   - iPhone (Safari): 共有ボタンアイコン ＞ **「ホーム画面に追加」**
   - Android (Chrome): メニューアイコン（縦3点） ＞ **「ホーム画面に追加」** または **「アプリをインストール」**

### 【方法2】 Google Apps Script (GAS) で直接配信
1. GASエディタ左側の「＋」＞「HTML」をクリックし、ファイル名を `index` とします。
2. `index.html` の内容をコピー＆ペーストします。
3. デプロイ設定でWebアプリとして「全員」に公開すると、GASのWebアプリURL（`.../exec`）を開くだけでスマホから予約画面が表示されます。

## 📁 ファイル構成

- `index.html` - メインUI画面 (タイムライン、予約フォーム、モーダル、モバイルPWA対応)
- `styles.css` - UIスタイリング (スマホ・タブレット完全レスポンシブ・Stickyカラム対応)
- `app.js` - フロントエンドロジック (重複チェック、タイムライングリッド計算、API通信)
- `gas_backend.js` - Google Apps Script用バックエンドコード (Google Drive連動・HTML直配信対応)
- `manifest.json` - PWA (ホーム画面に追加) 用設定ファイル
- `README.md` - 本ドキュメント

## 💡 トラブルシューティング

- **「指定された時間帯には既に他の予約が入っています」と表示される**
  - 同一リソースで利用時間が少しでも重複している場合に発生します。予約時間またはリソースを変更してください。
- **データがGoogle Driveに反映されない**
  - デプロイ時のアクセス許可が「全員」になっているか確認してください。
  - 「Drive設定」画面で正しいGAS WebアプリURLが設定されているか確認してください。
- **スマホでキーボードが開いた際に画面が勝手に拡大表示される**
  - iPhone等の仕様です。入力枠のフォントサイズを16px以上に自動調整済みですので、通常は問題なく操作いただけます。
